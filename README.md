# magic-web

The website for MAgic! Creative Studio (Asunción, Paraguay). Each iteration lives in its own
folder and is self-contained: its own dependencies, build and README.

| Folder | What it is |
|---|---|
| `legacy/` | The coming-soon page that was live at magic.com.py, plus early HTML drafts |
| `v1/` | First full landing page: Next.js static export |
| `v2/` | Second iteration: Astro |
| `claude_design/` | Design explorations and the original brand book upload |
| `docs/` | Project notes |

To work on a version, `cd` into its folder and follow its README.
